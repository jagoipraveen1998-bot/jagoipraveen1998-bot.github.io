Daily Brief Uploader

A personal automation tool for my own YouTube channel

This tool uses ▶ YouTube API Services

Daily Brief Uploader is a private tool that prepares a short daily news summary video and uploads it to the owner's own YouTube channel, India Daily Brief, using the YouTube Data API (videos.insert and thumbnails.set).

How it works

  1. Each morning a scheduled job collects public news headlines from RSS feeds.
  2. It writes a narration script, creates a voice-over and assembles a video.
  3. It uploads the video and its thumbnail to the owner's channel through the YouTube Data API, signed in with the owner's own Google account (OAuth 2.0).

It is used only by the channel owner. It offers no sign-in to other people and does not access anyone else's account or data.
