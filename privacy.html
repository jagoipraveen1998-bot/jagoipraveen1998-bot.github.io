Privacy Policy

Daily Brief Uploader - last updated 22 October 2026

Daily Brief Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What data it uses

The tool uses Google OAuth with the YouTube Data API only to upload videos and thumbnails to the owner's channel. It does not read, collect, store or share personal data of any other user.

Storage

The only stored credential is the owner's own access token, kept as an encrypted secret in the owner's private repository. No data is sold or shared with third parties.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
