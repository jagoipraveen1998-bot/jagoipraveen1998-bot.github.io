Privacy Policy

Daily Brief Uploader · last updated 22 October 2026

Daily Brief Uploader ("the tool") is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Information processed through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

What data the tool accesses

With the owner's permission (Google OAuth 2.0), the tool uses the scopes youtube.upload and youtube only to upload new videos and set their thumbnails on the owner's channel. It does not read, collect, analyse, sell or share personal data of any user, and it does not access other channels or viewers' data.

How data is stored

The only stored item is the owner's own OAuth refresh token, kept as an encrypted secret in the owner's private repository and used solely to authorise uploads. The tool does not use cookies and does not store any YouTube API data beyond the ID of each uploaded video in a private log.

Sharing

No data obtained through YouTube API Services is shared with third parties.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. On request, or when access is revoked, the stored token and upload log are deleted within 7 days. To request deletion, email jagoipraveen1998@gmail.com.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
